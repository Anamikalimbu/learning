# Content Ideas

A lightweight tracker for content ideas, from first draft through publication or archiving.

## What it does

- Add an idea and choose a type: Video, Blog, or Post.
- Set its status to Draft, Published, or Archived.
- Filter the list by type and status.
- Edit or delete an idea.

## Files

- `index.html` contains the idea form, filters, and idea list.
- `script.js` handles saving, editing, filtering, and deleting ideas.
- The shared styles and UI helpers are in the parent folder's `style.css` and `shared.js`.

Ideas are stored in this browser's local storage under `contentIdeas`. They are not synced to other browsers or devices.
